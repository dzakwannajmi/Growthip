# Growthip Limitations

Growthip is currently a hackathon and testnet prototype.

## Current Limitations

- Not audited
- Not production-ready
- Not deployed to mainnet
- No frontend yet
- No production Merkle tree service yet
- No production note delivery system yet
- No relayer system
- No timing privacy guarantee
- Small anonymity set in the current demo
- Recipient hash binding is currently prototype-level
- Testnet deployment only

## Privacy Limitations

Growthip protects the direct deposit-to-claim link at the ZK proof level.

However, it does not fully protect against:

- timing analysis
- small anonymity sets
- off-chain metadata leaks
- wallet behavior analysis
- social correlation

## Security Limitations

The current version is not audited.

Do not use real funds.

The project should be treated as a proof-of-concept for privacy-preserving creator tipping on Stellar.

## Not a Mixer

Growthip is not designed as a mixer or full private wallet.

It is a creator support prototype focused on private tipping and recipient-bound claims.
